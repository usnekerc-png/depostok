# Depo Stok Android

Bu klasör `Depo Stok` Android uygulamasını üretir.

- Paket: `com.anvecan.depostok`
- Minimum Android: 7.0 (API 24)
- Uygulama adı: **Depo Stok**
- Web arayüzü build sırasında repo kökündeki `index.html`, `app.js`, `styles.css`, `logo.png` dosyalarından APK içine kopyalanır.
- Veriler mevcut Supabase altyapısında ortak tutulmaya devam eder.

GitHub Actions her güncellemede install edilebilir APK üretir.

APK build tetikleyici: 2026-08-21
